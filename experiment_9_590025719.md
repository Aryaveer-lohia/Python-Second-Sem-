## ✧ THE FOUNDATION ✧
*The Theory of Entities*

In the realm of Python, everything is an object. A **Class** serves as the ethereal blueprint, while an **Object** is its tangible manifestation. 

*   **Encapsulation:** Binding data and methods within a single unit.
*   **Inheritance:** The passing of wisdom (attributes and methods) from a Parent to a Child.
*   **Polymorphism:** The ability of different entities to respond to the same call in their own unique way (Method Overriding and Operator Overloading).

## ✧ THE CREATION ✧
*The Implementation of Logic*

### 1. The Student Entity
```python
class Student:
    """The blueprint for a Student entity, capturing academic essence."""
    
    def __init__(self, name, sap_id, physics, chemistry, maths):
        self.name = name
        self.sap_id = sap_id
        self.marks = {
            "Physics": physics, 
            "Chemistry": chemistry, 
            "Maths": maths
        }

    def display_profile(self):
        """Reveals the student's profile to the world."""
        print(f"\n--- Profile: {self.name} ---")
        print(f"SAP ID: {self.sap_id}")
        print(f"Academic Record: {self.marks}")

    def calculate_percentage(self):
        """Distills the marks into a single percentage."""
        return sum(self.marks.values()) / len(self.marks)

    def determine_result(self):
        """Determines if the student has transcended the threshold of 40."""
        return "Pass ✧" if all(mark > 40 for mark in self.marks.values()) else "Fail"

def calculate_class_average(student_list):
    """Orchestrates the average of an entire cohort."""
    if not student_list:
        return 0
    return sum(s.calculate_percentage() for s in student_list) / len(student_list)
```

### 2. The Legacy of Inheritance
```python
# --- Single Inheritance ---
class Parent:
    def speak(self): print("The voice of the Parent.")

class Child(Parent):
    def play(self): print("The energy of the Child.")

# --- Multiple Inheritance ---
class Father:
    def garden(self): print("Father's touch in the garden.")

class Mother:
    def cook(self): print("Mother's love in the kitchen.")

class Prodigy(Father, Mother):
    def code(self): print("The Prodigy codes with soul.")
```

### 3. The Polymorphic Overload
```python
class Point:
    """A point in the infinite 2D plane."""
    
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __add__(self, other):
        """Overloading the '+' operator to merge two points."""
        return Point(self.x + other.x, self.y + other.y)

    def __str__(self):
        """The string manifestation of the point."""
        return f"Point(x={self.x}, y={self.y})"
```
